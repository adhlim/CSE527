## Reading notes
- All accuracy numbers are validation (HPatches 580 pairs, COCO synthetic 192 pairs), pooled precision at 3 px. MegaDepth-1500 is still unused.
- Table 1: quantization loss = A − B (float cosine → reconstruction cosine); distance loss = B − D (reconstruction cosine → bin-index L1).
  The split is about 50/50 only for HPatches at 8 bins. It is 26/74 for HPatches at 16 bins and 74/26 for COCO at 8 bins.
- Table 2: the float baseline for speedups is the single-GEMM NumPy/BLAS matcher, the fastest float arm measured
  (the C++ fused float arm was slower). Two-image timing is Colab (Xeon 2.20 GHz, 2 threads) and includes encoding;
  1-NN scaling is the laptop VM (Core Ultra 7 155H, 2 threads), N ≥ 65,536 only, range over 3 sizes × 2 runs.
- The 4-bit packed method has no two-image timing; the 3-bit packed (24 B) representation has no timing at all.
- Figure 2: x positions are evenly spaced bit-widths (2, 3, 4, 5, 8), not a linear axis. Dashed lines = one set of edges shared by all 64 dimensions.
